# Nexa Women - E-commerce Fashion & Beauty

Site de shopping en ligne pour la mode, la beauté et le lifestyle féminin.

## 🌟 Fonctionnalités

- **Multi-langue** : Français, Anglais, Arabe
- **Design responsive** : Mobile, tablet, desktop
- **Authentification** : Login & Register
- **Authentification Google** : Connexion facile
- **Thème clair/sombre** : Confortable pour tous
- **Panier** : Gestion des articles
- **Catalogue produits** : Filtrés par catégorie

## 🚀 Démarrage rapide

1. Clonez le repo :
```bash
git clone https://github.com/yourusername/nexa-women.git
cd nexa-women
```

2. Ouvrez `index.html` dans votre navigateur

## 📱 Multilingue

- **FR** : Français
- **EN** : English
- **AR** : العربية

Sélectionnez votre langue en haut à gauche du site.

## 🛠️ Technologies

- HTML5
- CSS3 (Grid, Flexbox, Variables CSS)
- JavaScript vanilla (pas de framework)
- Google Identity Services API

- Beauté & Soins

- Tech & Gadgets
